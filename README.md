# 🎭 Speech and Facial Based Emotion Detection using VR and Machine Learning

An AI/ML-based emotion detection system that identifies human emotions using **facial expressions and speech signals**. The project combines computer vision, deep learning, and speech emotion recognition to provide emotion predictions.

## 🚀 Features

* 😊 Facial Emotion Detection
* 🎤 Speech Emotion Detection
* 🧠 Deep Learning-based emotion classification
* 📷 Real-time face detection using OpenCV
* 🔊 Speech-based emotion recognition
* 🔗 Fusion of facial and speech emotion predictions
* 🖥️ Interactive application interface

## 🛠️ Technologies Used

* Python
* TensorFlow / Keras
* OpenCV
* NumPy
* Pandas
* Tkinter
* Jupyter Notebook
* Machine Learning
* Deep Learning
* CNN

## 📂 Project Files

| File                                  | Description                             |
| ------------------------------------- | --------------------------------------- |
| `app.py`                              | Main application                        |
| `emotion_model.h5`                    | Facial emotion detection model          |
| `speech_emotion_model_v2.h5`          | Speech emotion detection model          |
| `haarcascade_frontalface_default.xml` | Face detection classifier               |
| `emotion_fusion.ipynb`                | Facial + speech emotion fusion          |
| `speech_emotion_detection.ipynb`      | Speech emotion detection implementation |

## 📊 Datasets

* **FER2013** – Facial emotion recognition
* **RAVDESS** – Speech emotion recognition

## ⚙️ How to Run

### 1. Clone the repository

```bash
git clone YOUR_REPOSITORY_URL
```

### 2. Open the project folder

```bash
cd Emotion-Detection-using-VR-and-ML
```

### 3. Install required libraries

```bash
pip install tensorflow opencv-python numpy pandas
```

### 4. Run the application

```bash
python app.py
```

## 🎯 Project Objective

The objective of this project is to develop an AI-based system capable of recognizing human emotions from both **facial expressions and speech**, providing a more comprehensive approach to emotion detection.
